# 김해준 게임 QA 포트폴리오 홈페이지

https://godmode59.github.io/

GitHub Pages로 배포하는 정적 홈페이지입니다. HTML·CSS·JavaScript로 구성되며 별도 설치나 빌드가 필요하지 않습니다.

## 자료와 업데이트

- 공개 내용 기준: https://github.com/Godmode59/game-qa-portfolio
- `index.html`: 소개와 대표 사례
- `cases/`: 사례별 상세 기록
- `assets/`: 공개 포트폴리오의 화면 증빙
- `style.css`, `app.js`: 반응형 스타일과 분류·모바일 메뉴
- PDF는 기존 공개 포트폴리오 원본으로 연결합니다.

내용을 갱신할 때 최신 공개 자료와 대조하고, 담당 범위·수정 내역·재검증 여부를 구분합니다. 비공개 이력서, 개인 증빙, 수업 대화와 로컬 학습 기록을 그대로 공개하지 않습니다.

Pages 배포 소스는 main 브랜치의 루트입니다. 변경을 커밋하면 다시 배포됩니다.

게임 화면은 작업 사례를 설명하기 위한 증빙이며 각 게임의 권리는 해당 권리자에게 있습니다.
